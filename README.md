A modular, reproducible Machine Learning pipeline and interactive triage interface for classifying network flows as **Normal (`0`)** or **Suspicious (`1`)** to support Security Operations Center (SOC) alert prioritization.

---

## Architecture Overview

```text
configs/config.yaml (SSOT)
   |
   +--> src/data_loader.py --> src/eda.py --> reports/figures/*.png
   |
   +--> src/preprocessing.py (ColumnTransformer)
           |
           v
        src/models.py (LogReg | RandomForest | HistGradientBoosting)
           |
           v
        src/evaluate.py --> src/pipeline.py (Authoritative Producer)
                               |--> reports/metrics.json
                               |--> data/processed/*.parquet
                               +--> models/best_model.joblib --> app.py (Streamlit UI)
```

### Core Engineering Principles
- **Single Source of Truth:** All file paths, random seeds (`42`), sampling controls, feature schemas, and model hyperparameters are centralized in [`configs/config.yaml`](configs/config.yaml).
- **Single Artifact Producer:** [`src/pipeline.py`](src/pipeline.py) is the sole module responsible for training, evaluating, and persisting `models/best_model.joblib`, `reports/metrics.json`, processed splits, and figures.
- **Leakage-Free Preprocessing:** Target-leaking metadata (`attack_cat`) is excluded prior to transformation; imputation, scaling, and one-hot encoding (`handle_unknown="ignore"`) are fitted strictly on the training split inside `scikit-learn` `Pipeline` objects.

## Benchmark Results (Full UNSW-NB15 Test Split — 82,332 Flows)

| Model | Role | Accuracy | Precision | Recall | F1-Score | ROC-AUC |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| `LogisticRegression` | Linear Baseline | 0.7969 | 0.7417 | 0.9682 | 0.8400 | 0.9110 |
| `RandomForestClassifier` | **Selected (Max Recall)** | 0.8450 | 0.7876 | **0.9837** | 0.8748 | 0.9789 |
| `HistGradientBoostingClassifier` | Balanced Boosting | **0.9068** | **0.8941** | 0.9423 | **0.9176** | **0.9803** |

> **Operational Trade-Off:** `RandomForestClassifier` minimizes missed intrusions (**98.37% Recall**, 738 false negatives), whereas `HistGradientBoostingClassifier` cuts false-positive alerts by **58%** (5,059 vs. 12,023) while maintaining **94.23% Recall** and **0.9176 F1-Score**.

## Quickstart

### 1. Environment Setup
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.lock.txt
```

### 2. Run the End-to-End Pipeline
Generates EDA figures, processed splits, `reports/metrics.json`, and `models/best_model.joblib`:
```powershell
.\.venv\Scripts\python.exe -m src.pipeline
```
*Tip: For fast local prototyping, set `max_train_rows` and `max_test_rows` in [`configs/config.yaml`](configs/config.yaml) (e.g., `20000` / `10000`); set both to `null` for the full dataset.*

### 3. Run Automated Tests
```powershell
.\.venv\Scripts\python.exe -m pytest -v
```
Verifies missing-file handling, empty DataFrames, missing schema columns, stratified sampling, leakage exclusion, and graceful handling of `NaN`, corrupt numeric strings, and unseen categorical values.

### 4. Launch the SOC Triage UI
```powershell
.\.venv\Scripts\streamlit.exe run app.py
```
Supports batch `.parquet` flow scoring with triage priority tiers (`HIGH`, `MEDIUM`, `LOW`) and single-flow interactive inspection.

## Operational Scope
This system is designed as a **decision-support triage tool** to assist analysts in prioritizing suspicious network flows. It is **not** intended for autonomous inline traffic blocking without human-in-the-loop verification and local network baseline calibration.
