# Network Intrusion Triage (UNSW-NB15)

**Student:** Awais Ahmad (ID: 17007)  
**Course:** Programming for Artificial Intelligence (Fall 2026) — CUSIT  
**Course Coordinator:** Syed Muhammad Mohuddin  

An end-to-end, reproducible Machine Learning triage pipeline built on the **UNSW-NB15** dataset to classify network flows as `Normal` (`0`) or `Suspicious` (`1`) for Security Operations Center (SOC) analyst support.

> **Academic Disclaimer:** This is a classroom prototype trained on the UNSW-NB15 benchmark dataset. It is intended solely for decision-support triage demonstrations and **must not** be deployed as an autonomous production firewall or IPS.

## Setup Instructions
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.lock.txt
```

## Usage
1. **Run the authoritative end-to-end pipeline** (generates EDA plots, processed splits, `reports/metrics.json`, and `models/best_model.joblib`):
   ```powershell
   .\.venv\Scripts\python.exe -m src.pipeline
   ```
   *(To run on the full dataset instead of the development subset, set `max_train_rows: null` and `max_test_rows: null` in `configs/config.yaml`.)*

2. **Run automated unit & edge-case tests:**
   ```powershell
   .\.venv\Scripts\python.exe -m pytest -v
   ```

3. **Launch the Streamlit SOC Triage UI:**
   ```powershell
   .\.venv\Scripts\streamlit.exe run app.py
   ```
